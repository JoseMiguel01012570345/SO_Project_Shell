# SO_Project_Shell

This project is a custom shell implementation. It aims to provide a basic understanding of how shells work by implementing core functionalities.

## Features

- Command execution
- Input/output redirection
- Piping between commands
- Background process handling
- Built-in commands (e.g., `cd`, `exit`)

## Prerequisites

- GCC or any C compiler
- Unix-based operating system (Linux/MacOS)

## Installation

1. Clone the repository:
    ```bash
    git clone <repository-url>
    ```
2. Navigate to the project directory:
    ```bash
    cd SO_Project_Shell
    ```
3. Compile the shell:
    ```bash
    gcc -o shell shell.c
    ```

## Usage

Run the shell using:
```bash
./shell
```

## Project Structure

- `shell.c`: Main implementation of the shell.
- `README.md`: Project documentation.
